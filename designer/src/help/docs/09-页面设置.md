# 页面设置

通过画布工具栏的 **"页面设置"** 按钮（显示当前纸张信息，如"A4 (竖向)"），可以打开页面设置弹窗。

---

## 纸张尺寸

| 预设 | 尺寸（mm） |
|------|-----------|
| **A4** | 210 × 297 |
| **A5** | 148 × 210 |
| **自定义** | 宽度 50 ~ 500mm，高度 50 ~ 500mm |
| **连续纸** | 宽度 20 ~ 500mm，高度自适应（默认 80mm 宽，常见热敏打印机） |

![页面设置弹窗](/images/page-setting.png)

---

## 纸张方向

- **竖向**：默认方向
- **横向**：宽高互换

> ⚠️ 连续纸模式不支持横向。

---

## 页边距

分别设置四个方向的边距：

| 配置项 | 范围 |
|--------|------|
| 上边距 | 0~50mm |
| 右边距 | 0~50mm |
| 下边距 | 0~50mm |
| 左边距 | 0~50mm |

---

## 页头区域

| 配置项 | 说明 |
|--------|------|
| 启用 | 开关，是否显示页头区域 |
| 高度 | 1~100mm |

页头区域位于页面顶部，适合放置公司 Logo、单据标题等需要在每页重复出现的内容。

> ⚠️ 连续纸模式下，页头区域强制关闭。

---

## 页脚区域

| 配置项 | 说明 |
|--------|------|
| 启用 | 开关，是否显示页脚区域 |
| 高度 | 1~100mm |

页脚区域位于页面底部，适合放置签章区域、备注说明等内容。

> ⚠️ 连续纸模式下，页脚区域强制关闭。

---

## 页码配置

启用页码后，系统会在打印输出时自动添加页码。

### 基本配置

| 配置项 | 说明 |
|--------|------|
| 启用 | 开关 |
| 位置 | 左上角 / 顶部居中 / 右上角 / 左下角 / 底部居中 / 右下角 |
| 格式 | 斜线（1/3）/ 文字（第1页 共3页）/ 简单（1） |

### 样式配置

| 配置项 | 说明 |
|--------|------|
| 字号 | 8~24px |
| 颜色 | 颜色选择器 |
| 字重 | 正常 / 加粗 |

### 高级配置

| 配置项 | 说明 |
|--------|------|
| 前缀 | 页码前的文字 |
| 后缀 | 页码后的文字 |
| 分隔符 | 页码和总页数之间的分隔符 |
| X 偏移 | 水平偏移量 |
| Y 偏移 | 垂直偏移量 |

启用页码后，设计器画布上会显示 **蓝色虚线框** 预览页码的位置。

# 组件使用指南

设计器支持 7 种组件类型，分为三大类：基础组件、装饰组件和编码组件。

---

## 添加组件

### 方式一：从组件库添加

1. 在左侧面板切换到 **"组件库"** 标签页
2. 找到需要的组件
3. **双击** 快速添加到画布中心，或 **拖拽** 到指定位置

![组件库](/images/component-library.png)

### 方式二：从数据资产自动生成

从数据资产面板拖拽字段到画布，系统会自动创建对应类型的组件并绑定数据：
- 普通字段 → 自动创建 **文本组件**
- 数组字段 → 自动创建 **表格组件**

## 基础组件

### 文本组件（text）

用于显示文字内容，支持数据绑定和静态文本。

| 配置项 | 说明 |
|--------|------|
| 默认尺寸 | 60mm × 10mm |
| 标签（Label） | 前缀标签文本，如 "姓名：" |
| 静态文本 | 不绑定数据时显示的固定文字 |
| 字体大小 | 文字大小（px） |
| 字重 | 常规 / 加粗 |
| 对齐方式 | 左对齐 / 居中 / 右对齐 |
| 字体颜色 | 颜色选择器 |

### 图片组件（image）

用于显示图片，支持 URL 和 Base64 格式。

| 配置项 | 说明 |
|--------|------|
| 默认尺寸 | 60mm × 40mm |
| 数据绑定 | 绑定图片 URL 或 Base64 路径 |
| 回退值 | 图片加载失败时的占位内容 |

### 表格组件（table）

用于展示列表数据，支持分页、合计等高级功能。详见 **"表格高级配置"** 章节。

| 配置项 | 说明 |
|--------|------|
| 默认尺寸 | 铺满可用宽度 × 60mm |
| 数据绑定 | 绑定数组类型字段 |
| 列配置 | 配置每列的标题、数据字段、宽度 |
| 表头/边框 | 开关及样式配置 |
| 列级样式 | 每列可独立配置表头和数据单元格样式 |
| 合计行 | 支持 SUM/AVG/MAX/MIN/COUNT 聚合 |
| 表格密度 | `normal` / `compact` 两种密度预设 |

> ⚠️ 表格组件不能放入页头或页脚区域。

---

## 装饰组件

### 线条组件（line）

用于分隔内容或装饰。

| 配置项 | 说明 |
|--------|------|
| 默认尺寸 | 铺满可用宽度 × 5mm |
| 线条粗细 | 1~20px |
| 线条样式 | 实线 / 虚线 / 点线 |
| 线条颜色 | 颜色选择器 |

### 矩形组件（rect）

用于绘制边框装饰。

| 配置项 | 说明 |
|--------|------|
| 默认尺寸 | 60mm × 15mm |
| 用途 | 画框、分隔区域等 |

---

## 编码组件

### 二维码组件（qrcode）

根据绑定的数据生成二维码图片。

| 配置项 | 说明 |
|--------|------|
| 默认尺寸 | 30mm × 30mm |
| 数据绑定 | 绑定需要编码为二维码的内容 |

### 条形码组件（barcode）

根据绑定的数据生成条形码图片（CODE128 格式）。

| 配置项 | 说明 |
|--------|------|
| 默认尺寸 | 60mm × 20mm |
| 数据绑定 | 绑定需要编码为条形码的内容 |

---

## 属性面板

选中组件后，右侧属性面板显示该组件的配置选项，分为四个区域：

![属性面板](/images/property-panel.png)

| 区域 | 内容 |
|------|------|
| **布局属性** | X/Y 坐标（mm）、宽度/高度（mm），精度 0.1mm |
| **数据绑定** | 绑定路径、回退值、管道配置（仅 text/image/qrcode/barcode/table） |
| **样式属性** | 组件特有的样式配置（字体、颜色、线条样式等） |
| **表格列管理** | 仅表格组件显示，管理列配置、列级样式和合计设置 |

---

## 表格列级样式

选中表格组件并展开 **"表格列管理"** 后，每列支持独立配置以下样式：

### 表头单元格样式

| 配置项 | 说明 |
|--------|------|
| 字体大小 | 表头文字字号（px） |
| 字重 | 表头文字粗细，如 `normal`、`bold`、`600` |
| 字体颜色 | 表头文字颜色 |
| 对齐方式 | 左对齐 / 居中 / 右对齐 |
| 背景颜色 | 表头背景色（设计器暂不开放 UI） |

### 数据单元格样式

| 配置项 | 说明 |
|--------|------|
| 字体大小 | 数据行文字字号（px） |
| 字重 | 数据行文字粗细 |
| 字体颜色 | 数据行文字颜色 |
| 对齐方式 | 左对齐 / 居中 / 右对齐 |
| 背景颜色 | 数据行背景色（设计器暂不开放 UI） |

> 💡 列级样式的优先级高于表格级默认样式，可用于突出显示金额列、标题列等。

---

## 组件树

右侧面板的 **"组件树"** 标签页以树状结构展示所有组件：

- 按区域分组：页头区域、内容区域、页脚区域
- 每个组件显示图标 + 类型名 + 序号 + 数据绑定路径
- 单击组件名称可在画布中选中对应组件
- 右键菜单支持复制和删除组件

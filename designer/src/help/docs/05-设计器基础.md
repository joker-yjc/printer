# 设计器基础

设计器是打印模板平台的核心编辑界面，采用三栏布局，提供可视化的模板设计体验。

---

## 界面布局

![设计器界面](/images/designer-overview.png)

设计器由三个主要区域组成：

| 区域 | 宽度 | 功能 |
|------|------|------|
| **左侧面板** | 280px | 资源面板：数据资产 + 组件库 |
| **中间画布** | 自适应 | 模板编辑区域，所见即所得 |
| **右侧面板** | 320px | 属性配置 / 组件树（Tab 切换） |

左右面板均可折叠，折叠按钮位于面板边缘中部。

## 画布编辑器

画布是模板设计的核心区域，具有以下特性：

### 标尺与页边距

- 画布顶部和左侧显示 **标尺**（毫米刻度）
- 页边距以 **半透明黄色边框** 标识
- 虚线框标识可用编辑区域

### 三个区域

| 区域 | 说明 |
|------|------|
| **页头区域** | 可选，位于页面顶部，需手动开启 |
| **内容区域** | 主要编辑区域，放置打印内容 |
| **页脚区域** | 可选，位于页面底部，需手动开启 |

> ⚠️ 连续纸模式下，页头和页脚区域不可用。

### 区域高度调整

页头和页脚区域的高度支持两种调整方式：

#### 方式一：属性面板输入数值

选中页头或页脚区域后，在右侧属性面板中设置 **最小高度**：

- 页头高度范围：`1 ~ 100mm`
- 页脚高度范围：`1 ~ 100mm`
- 设置的最小高度会作为区域的**高度下限**

#### 方式二：拖拽边框调整

- 页头底部和页脚顶部各有一个 **拖拽手柄**
- 鼠标拖拽可快速调整区域高度
- 拖拽时不会低于设定的最小高度

#### 自动撑高行为

当页头/页脚内的组件被拖拽到内容区域时，区域高度**不会自动撑高**，而是保持在最小高度约束范围内。如需更大的空间，请通过上述两种方式手动调整。

> 💡 建议：先设置一个略大于内容的最小高度，再根据需要拖拽边框微调。

## 组件操作

### 选择组件

- **单击**：选中单个组件
- **Ctrl/Cmd + 点击**：多选组件

### 拖拽移动

选中组件后，直接拖拽到新位置。支持多选整体拖拽。

### 网格吸附

- 默认启用 **5mm 网格吸附**，拖拽时自动对齐
- 按住 **Shift 键** 可临时禁用吸附，进行精确移动
- 工具栏的"网格"按钮可开关网格功能

### 智能对齐参考线

拖拽组件时，系统自动检测与其他组件的对齐关系（左对齐、居中、右对齐、顶部对齐、底部对齐等），并显示 **蓝色参考线** 辅助对齐。

### 尺寸调整

选中组件后，组件四角和四边出现 **缩放手柄**，拖拽手柄调整组件大小。

### 右键菜单

右键点击组件，弹出操作菜单：

| 菜单项 | 快捷键 | 说明 |
|--------|--------|------|
| 复制 | Ctrl+C | 复制到剪贴板 |
| 克隆 | Ctrl+D | 在原位置旁创建副本 |
| 置顶 | — | 将组件置于最上层 |
| 上移一层 | — | 上移一个层级 |
| 下移一层 | — | 下移一个层级 |
| 置底 | — | 将组件置于最下层 |
| 删除 | Delete | 删除组件 |

### 超出边界提示

当组件超出页面边界时，会显示 **红色警示样式** 提示您调整位置。

## 画布工具栏

工具栏位于画布顶部，提供以下功能：

| 功能 | 说明 | 条件 |
|------|------|------|
| ↩️ 撤销 | 撤销上一步操作（最多 20 步） | — |
| ↪️ 重做 | 重做已撤销的操作 | — |
| 对齐工具 | 左对齐/居中/右对齐/顶部对齐/垂直居中/底部对齐 | 需选中 2+ 组件 |
| 分布工具 | 水平分布/垂直分布 | 需选中 3+ 组件 |
| 页面设置 | 显示当前纸张，点击打开设置弹窗 | — |
| 网格开关 | 开关 5mm 网格吸附 | — |
| 测试打印 | 打开打印预览弹窗 | — |
| 保存 | 保存模板 | — |
| 重置 | 清空画布 | — |

## 缩放控制

右下角悬浮按钮组提供缩放控件：

- 🔍 **放大**：每次放大 25%（快捷键 `Ctrl++`）
- 🔍 **缩小**：每次缩小 25%（快捷键 `Ctrl+-`）
- 🖥️ **重置**：恢复 100%（快捷键 `Ctrl+0`）

缩放范围：25% ~ 200%。

## 调试面板

点击右下角悬浮按钮组中的 **"调试"** 按钮（`< >` 图标），打开右侧调试抽屉：

- 显示模板名称、Schema ID、组件数量统计
- 展示完整的模板 JSON Schema
- 提供"复制 JSON"按钮，方便调试

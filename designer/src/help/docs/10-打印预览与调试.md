# 打印预览与调试

打印预览功能允许您在正式打印前查看模板的实际渲染效果。

---

## 测试打印

### 操作步骤

1. 点击画布工具栏的 **"测试打印"** 按钮
2. 在弹窗中输入测试数据（JSON 格式）
3. 点击 **"生成预览"** 按钮
4. 系统使用打印引擎渲染 HTML，并在 iframe 中显示预览效果

![打印预览弹窗](/images/print-preview.png)

### 单份打印

输入单个 JSON 对象，预览单份文档的打印效果：

```json
{
  "orderNo": "ORD-20250101-001",
  "customerName": "张三",
  "orderDate": "2025-01-01",
  "totalAmount": 299.00
}
```

### 批量打印

输入 JSON 数组，系统自动识别并生成多份文档预览：

```json
[
  { "orderNo": "ORD-001", "customerName": "张三" },
  { "orderNo": "ORD-002", "customerName": "李四" },
  { "orderNo": "ORD-003", "customerName": "王五" }
]
```

批量模式下：
- 每份文档间显示分隔线和序号
- 底部显示页码导航：上一页 / 下一页 / 第 X 页 / 共 Y 页

---

## 打印输出

预览满意后，点击 **"打印"** 按钮：

- 系统打开新窗口执行打印
- 打印前会等待所有图片加载完成
- 使用浏览器原生打印对话框

---

## 调试面板

点击设计器右下角悬浮按钮组中的 **"< >"** 图标，打开调试抽屉。

![调试面板](/images/debug-panel.png)

### 面板内容

| 信息 | 说明 |
|------|------|
| 模板名称 | 当前模板的名称 |
| Schema ID | 关联的 Schema 标识 |
| 组件数量 | 页头 / 内容 / 页脚 分别统计 |
| JSON Schema | 完整的模板 JSON 结构 |

### 复制 JSON

点击 **"复制 JSON"** 按钮，将模板的完整 JSON Schema 复制到剪贴板，可用于：

- 开发人员集成调试
- 模板备份和迁移
- 问题排查

---

## 常见问题排查

### 数据未显示

- 检查绑定路径是否正确（注意大小写和点号分隔）
- 检查测试数据的 JSON 格式是否正确
- 检查是否配置了回退值

### 组件超出边界

- 组件显示红色警示时，表示超出了页面边界
- 在属性面板调整 X/Y 坐标或宽度/高度

### 表格分页不正确

- 检查表格高度是否合理
- 确认"显示表头"开关已开启（如需每页显示表头）
- 查看合计模式设置（总计 vs 分页合计）

### 预览空白

- 确认已输入有效的 JSON 测试数据
- 检查 JSON 格式是否正确（注意引号和逗号）
- 尝试使用最简单的数据测试

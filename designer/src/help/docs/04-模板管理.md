# 模板管理

模板管理页面用于创建、查看、编辑和管理所有打印模板。

---

## 模板列表

进入 **侧边栏 → 模板管理**，可以看到所有模板的列表。

列表展示以下信息：

| 列名 | 说明 |
|------|------|
| 模板名称 | 模板的名称 |
| 关联 Schema | 该模板绑定的数据模型 |
| 组件数 | 模板中包含的组件总数 |
| 纸张尺寸 | 如 A4、A5、自定义等 |
| 描述 | 模板的备注描述 |
| 创建时间 | 模板创建时间 |

![模板列表页](/images/template-list.png)

---

## 新建模板

点击 **"新建模板"** 按钮，在弹窗中填写：

- **模板名称**（必填）：模板的名称
- **关联 Schema**（必填）：选择数据模型，模板将使用该 Schema 的字段进行数据绑定
- **描述**：可选

系统默认创建 **A4 竖向**模板，页边距 **5mm**。如需修改纸张设置，可在设计器的"页面设置"中调整。

![新建模板弹窗](/images/template-form.png)

---

## 模板操作

每个模板行提供以下操作按钮：

| 按钮 | 图标 | 说明 |
|------|------|------|
| 预览 | 👁️ | 弹窗查看模板详情（名称、尺寸、组件数等） |
| 在设计器中打开 | ✏️ | 进入可视化设计器编辑模板 |
| 复制 | 📋 | 创建该模板的副本 |
| 导出 | ⬇️ | 下载模板 JSON 文件 |
| 删除 | 🗑️ | 删除模板（需确认） |

---

## 搜索与过滤

页面顶部提供以下过滤功能：

- **搜索框**：按模板名称模糊搜索
- **Schema 筛选器**：按关联的 Schema 过滤

---

## 导入与导出

### 导入模板

- 点击 **"导入"** 按钮，上传 JSON 文件
- 支持单个和批量导入

### 导出模板

- **导出单个**：点击模板行的导出按钮
- **批量导出**：点击 **"批量导出"** 按钮，一次导出所有模板

> 💡 导出的 JSON 文件可以在其他环境中导入，实现模板的迁移和备份。

---

## 复制模板

点击 **"复制"** 按钮，系统会创建一个名称为 `原名称 - 副本` 的新模板，内容与原模板完全相同。适合在已有模板基础上快速创建新模板。

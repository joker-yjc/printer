# 表格高级配置

表格组件是打印模板中最复杂的组件，支持列管理、合计行、分页拆分等高级功能。

---

## 表格全局设置

选中表格组件后，属性面板显示 **"表格列管理"** 区域，包含以下全局设置：

### 显示表头

开关控制是否显示表格的表头行。

### 显示边框

- **开关**：是否显示表格边框
- **线条样式**：实线 / 虚线
- **线条粗细**：1~5px
- **线条颜色**：颜色选择器

### 显示序号列

- **开关**：是否在表格第一列显示序号
- **标题**：序号列的表头文字（默认"序号"）
- **宽度**：序号列的宽度（mm）

---

## 列配置

每列可以配置以下属性：

| 配置项 | 说明 |
|--------|------|
| 启用 | checkbox 控制该列是否显示 |
| 排序 | 上移/下移按钮调整列顺序 |
| 删除 | 删除该列 |
| 列标题 | 表头显示的文字 |
| 数据字段（dataIndex） | 对应数据中的字段名 |
| 列宽（mm） | 该列的宽度 |

### 列宽溢出检测

当所有列的宽度之和超过表格可用宽度时，系统会显示 **红色警告** 提示调整列宽。

---

## 合计行

### 启用合计

打开 **"显示合计行"** 开关后，可以配置：

| 配置项 | 说明 |
|--------|------|
| 合计模式 | **总计**（仅最后一页显示）/ **分页合计**（每页都显示） |
| 合计标签 | 首列显示的标签文字，如"合计" |

### 列合计配置

展开每列的合计配置区域：

| 配置项 | 说明 |
|--------|------|
| 聚合类型 | SUM（求和）/ AVG（平均）/ MAX（最大值）/ MIN（最小值）/ COUNT（计数） |
| 小数位数 | 0~10 位 |
| 管道转换 | 可选，限 money（金额）和 chineseNumber（中文大写）|
| 前缀 | 合计值前的文字，如 "¥" |
| 后缀 | 合计值后的文字，如 "元" |

### 合计配置示例

**场景：订单金额列求和，保留 2 位小数，前缀 ¥**

```
聚合类型：SUM
小数位数：2
管道转换：无
前缀：¥
后缀：
```

---

## 合计额外行

合计区域下方可以添加 **额外行**，用于显示附加信息（如金额大写）。

每个额外行可以配置多个数据项：

| 配置项 | 说明 |
|--------|------|
| 前缀文字 | 显示在数值前的文字，如"金额大写：" |
| 引用合计列 | 选择引用哪一列的合计值 |
| 管道转换 | 对合计值进行转换（如转为中文大写） |

### 额外行使用示例

**场景：在合计行下方显示金额大写**

1. 添加一个额外行
2. 添加数据项：
   - 前缀文字：`金额大写：`
   - 引用合计列：`totalAmount`
   - 管道转换：`chineseNumber`

效果：合计行下方显示 "金额大写：贰佰玖拾玖元整"

## 表格与分页

表格组件支持跨页拆分：

- 当表格数据量超过当前页面剩余空间时，自动拆分到下一页
- **渲染后测量方案**：系统在实际渲染后测量每行高度，确保分页精度
- **分页合计**：每页底部显示当前页的合计
- **总计**：仅在最后一页底部显示全部数据的合计

> 💡 如果需要在每一页都显示表头，请确保"显示表头"开关已开启。

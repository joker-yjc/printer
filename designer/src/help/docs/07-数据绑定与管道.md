# 数据绑定与管道

数据绑定是将 Schema 字段与组件关联起来的核心功能，使打印内容能够根据实际数据动态变化。

---

## 数据资产面板

在设计器左侧面板的 **"数据资产"** 标签页中：

1. 在顶部下拉框选择要使用的 Schema
2. 树状结构展示该 Schema 的所有字段
3. 每个字段显示图标 + 标签名（字段 key）

![数据资产面板](/images/data-asset-panel.png)

### 字段图标说明

| 图标颜色 | 类型 | 说明 |
|----------|------|------|
| 绿色 | string | 字符串字段 |
| 橙色 | number | 数字字段 |
| 青色 | boolean | 布尔字段 |
| 紫色 | date/datetime | 日期字段 |
| 灰色 | object | 对象（不可拖拽） |
| 蓝色 | array | 数组（表格数据源） |

> ⚠️ `object` 类型字段和 `array` 的子字段标记为"仅表格列"，不可直接拖拽到画布。

---

## 绑定方式

### 方式一：拖拽 / 双击（推荐）

- **普通字段**：双击或拖拽到画布 → 自动创建文本组件并绑定
- **数组字段**：双击或拖拽到画布 → 自动创建表格组件并创建列

### 方式二：手动配置

1. 选中已有组件
2. 在右侧属性面板找到 **"数据绑定"** 区域
3. 输入 **绑定路径**

![数据绑定配置](/images/data-binding-config.png)

---

## 路径语法

绑定路径使用**点号分隔**的方式访问嵌套字段：

| 路径 | 说明 |
|------|------|
| `orderNo` | 根级字段 |
| `customer.name` | 嵌套对象字段 |
| `order.customer.address` | 多层嵌套 |
| `items` | 数组字段（绑定到表格） |

### 表格列绑定

表格组件绑定数组字段后，每列的 `dataIndex` 填写数组子字段的 key（不含数组路径前缀）。

例如数组路径为 `items`，列的 dataIndex 填写 `productName`（而非 `items.productName`）。

---

## 回退值（Fallback）

当绑定的数据为空或不存在时，组件会显示回退值。

- 在属性面板的 **"回退值"** 输入框中设置
- 例如设置为 `"--"` 或 `"暂无数据"`

---

## 数据管道（Pipes）

管道用于在显示数据前进行转换处理。可以链式添加多个管道，按顺序依次执行。

### 添加管道

1. 在属性面板的数据绑定区域，找到 **"管道"** 下拉框
2. 选择要添加的管道类型
3. 配置管道的参数
4. 可继续添加更多管道

![管道配置](/images/data-binding-config.png)

### 可用管道类型

| 管道 | 功能 | 可配置参数 |
|------|------|-----------|
| **date** | 日期格式化 | 格式模板，如 `YYYY-MM-DD`、`YYYY年MM月DD日` |
| **currency** | 货币格式化 | 货币符号（如 ¥、$）、小数位数 |
| **money** | 金额转换 | 分转元、千分位分隔、中文大写金额 |
| **chineseNumber** | 中文大写数字 | 支持小数、负数、both 模式 |
| **slice** | 字符串截取 | 起始位置、结束位置 |
| **default** | 默认值 | 默认值文本 |
| **uppercase** | 大小写转换 | — |

### 管道使用示例

**场景：将日期字段格式化为中文格式**

1. 绑定路径：`orderDate`
2. 添加管道：`date`
3. 管道参数：格式 = `YYYY年MM月DD日`

**场景：将金额（分）转换为中文大写**

1. 绑定路径：`totalAmount`
2. 添加管道：`money`（参数：分转元 = 是）
3. 再添加管道：`chineseNumber`

> 💡 管道按添加顺序执行，前一个管道的输出是后一个的输入。

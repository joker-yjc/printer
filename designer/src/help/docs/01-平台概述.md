# 平台概述

打印模板平台是一款面向企业级文档打印场景的**可视化模板设计器**。通过拖拽式操作，您可以轻松设计出专业的打印模板，并绑定数据实现批量打印。

---

## 三大核心模块

平台由三个核心模块组成：

| 模块 | 功能 | 入口 |
|------|------|------|
| **Schema 字典管理** | 定义数据模型（字段结构），作为模板的数据源 | 侧边栏 → Schema 字典 |
| **模板管理** | 创建、管理和维护打印模板 | 侧边栏 → 模板管理 |
| **可视化设计器** | 拖拽式设计模板布局、绑定数据、配置样式 | 模板管理 → 在设计器中打开 |

![平台主界面](/images/template-list.png)

## 典型工作流

使用平台完成打印模板设计的典型流程：

1. **定义数据模型** — 在 Schema 管理中创建数据字典，定义打印单据包含哪些字段
2. **创建模板** — 在模板管理中新建模板，并关联对应的 Schema
3. **设计布局** — 在设计器中拖拽组件、调整位置和样式
4. **绑定数据** — 将 Schema 字段绑定到对应的组件上
5. **预览测试** — 输入测试数据，预览打印效果
6. **保存使用** — 保存模板，供后端打印服务调用

---

## 支持的组件类型

设计器支持以下 7 种组件：

| 组件 | 用途 |
|------|------|
| 文本 | 显示文字内容，支持数据绑定 |
| 图片 | 显示图片（URL/Base64） |
| 表格 | 展示列表数据，支持分页和合计 | 
| 线条 | 分隔线、装饰线 |
| 矩形 | 边框装饰 | 
| 二维码 | 生成二维码图片 | 
| 条形码 | 生成条形码图片 |

## 特色功能

- 📐 **精确坐标系统** — 使用毫米（mm）单位，精准控制打印位置
- 🧲 **网格吸附** — 自动对齐网格，保持布局整齐
- 📏 **对齐参考线** — 拖拽时自动显示对齐辅助线
- 🔗 **数据管道** — 支持日期格式化、金额转换、中文大写等多种数据转换
- 📄 **页码配置** — 支持多种页码位置和格式
- 📑 **页头页脚** — 可配置的页头页脚区域
- 🖨️ **批量打印** — 支持多份文档批量打印

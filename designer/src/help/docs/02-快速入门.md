# 快速入门

本章节将引导您从零开始创建第一个打印模板，帮助您快速熟悉平台的核心操作流程。

---

## 第 1 步：创建 Schema（数据模型）

Schema 定义了打印单据包含哪些数据字段。

1. 点击左侧菜单的 **"Schema 字典"** 进入 Schema 管理页面
2. 点击 **"新建 Schema"** 按钮
3. 填写基本信息：
   - **名称**：例如 `订单打印单`
   - **版本**：例如 `1.0.0`
   - **描述**：可选，描述该 Schema 的用途
4. 在 JSON 编辑器中定义字段结构，例如：

```json
{
  "root": {
    "type": "object",
    "children": {
      "orderNo": { "type": "string", "label": "订单号" },
      "customerName": { "type": "string", "label": "客户姓名" },
      "orderDate": { "type": "date", "label": "订单日期" },
      "totalAmount": { "type": "number", "label": "订单金额" },
      "items": {
        "type": "array",
        "label": "商品明细",
        "children": {
          "productName": { "type": "string", "label": "商品名称" },
          "quantity": { "type": "number", "label": "数量" },
          "price": { "type": "number", "label": "单价" }
        }
      }
    }
  }
}
```

5. 点击 **"确定"** 保存 Schema

> 💡 **快捷方式**：如果您已有 JSON 格式的示例数据，可以使用 **"从 Mock 数据生成"** 功能自动推断 Schema 结构，无需手写 JSON。

![Schema 列表页](/images/schema-list.png)

---

## 第 2 步：创建模板

1. 点击左侧菜单的 **"模板管理"**
2. 点击 **"新建模板"** 按钮
3. 填写模板信息：
   - **模板名称**：例如 `订单打印单-A4`
   - **关联 Schema**：选择刚才创建的 `订单打印单`
   - **描述**：可选
4. 点击 **"确定"**，系统会自动创建一个 A4 竖向的空白模板

![模板列表](/images/template-list.png)

---

## 第 3 步：进入设计器

在模板列表中，找到刚创建的模板，点击 **"在设计器中打开"** 按钮（编辑图标）。

设计器是一个三栏布局的全屏编辑界面：

- **左侧面板**：资源面板（数据资产 + 组件库）
- **中间区域**：画布编辑器
- **右侧面板**：属性配置 / 组件树

![设计器界面](/images/designer-overview.png)

---

## 第 4 步：添加组件并绑定数据

### 方式一：从数据资产拖拽（推荐）

1. 在左侧面板的 **"数据资产"** 标签页中，选择刚才关联的 Schema
2. 展开字段树，找到需要的字段（如 `orderNo`）
3. **双击字段** 或 **拖拽到画布** 上
4. 系统会自动创建文本组件并绑定对应的数据路径

### 方式二：从组件库手动添加

1. 切换到左侧面板的 **"组件库"** 标签页
2. 双击或拖拽需要的组件（如"文本"）到画布
3. 在右侧属性面板中，手动配置 **数据绑定** 路径

---

## 第 5 步：预览打印效果

1. 点击画布工具栏的 **"测试打印"** 按钮
2. 在弹窗中输入测试数据（JSON 格式）：

```json
{
  "orderNo": "ORD-20250101-001",
  "customerName": "张三",
  "orderDate": "2025-01-01",
  "totalAmount": 299.00,
  "items": [
    { "productName": "商品A", "quantity": 2, "price": 99.00 },
    { "productName": "商品B", "quantity": 1, "price": 101.00 }
  ]
}
```

3. 点击 **"生成预览"**，查看打印效果
4. 如果效果满意，关闭预览弹窗

![打印预览](/images/print-preview.png)

---

## 第 6 步：保存模板

点击画布工具栏的 **"保存"** 按钮，模板即保存成功。

现在您已经完成了第一个打印模板的创建！接下来可以查阅其他章节，了解更多高级功能。

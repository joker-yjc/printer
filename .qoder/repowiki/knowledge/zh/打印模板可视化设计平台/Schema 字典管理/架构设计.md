- **入口与状态管理**：`index.tsx` 作为主容器，维护 Schema 列表状态及模态框显隐逻辑，通过 `schemaApi` 进行数据交互。
- **组件分层**：采用“主页面 + 功能模态框”结构，`SchemaFormModal` 负责复杂表单与 JSON 编辑，`SchemaPreviewModal` 负责只读展示，`SchemaHelpModal` 提供规范指引。
- **核心逻辑**：内置 `inferSchemaFromData` 算法，支持从 JSON 样例自动递归推导 `SchemaField` 树状结构；在提交时强制校验根节点必须为 `key: 'root'` 且 `type: 'object'`。
- **编辑器集成**：在 `SchemaFormModal` 中集成 `@monaco-editor/react`，提供带语法高亮的 JSON 手动编辑与智能生成双模式。
- **数据契约**：严格遵循 `types/index.ts` 中定义的 `SchemaDictionary` 与 `SchemaField` 接口，确保数据结构的一致性。

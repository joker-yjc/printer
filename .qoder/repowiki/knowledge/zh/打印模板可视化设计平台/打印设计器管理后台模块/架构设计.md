- **模块化页面结构**：采用 `index.tsx`（主逻辑/列表）+ `components/`（表单/预览弹窗）的扁平化组织方式，实现视图与交互逻辑的解耦。
- **统一 API 适配层**：通过 `services/api.ts` 封装 CRUD 接口，利用环境变量 `VITE_USE_MOCK` 动态切换前端内存 Mock 或后端真实 HTTP 请求，实现开发与演示环境的无缝衔接。
- **复杂数据编辑方案**：集成 `@monaco-editor/react` 处理 Schema 和 Mock 数据的 JSON 结构化编辑，配合自定义工具栏（如“从 Mock 推断 Schema”、“根据 Schema 生成数据”）提升配置效率。
- **类型驱动开发**：深度依赖 `types/index.ts` 中定义的 `SchemaDictionary`、`PrintTemplate` 等核心接口，确保跨模块（管理页与设计器）的数据结构一致性。

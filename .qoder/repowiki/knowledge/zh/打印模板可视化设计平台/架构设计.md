- **路由驱动的功能分区**：顶层 `App.tsx` 采用嵌套路由架构，将 `/designer` 路径下的全屏画布编辑器与 `/templates`、`/schemas` 等管理后台页面在布局上进行物理隔离。
- **全局状态总线**：核心交互逻辑由 `src/store/designer.ts` (Zustand) 统一承载，作为跨组件通信的唯一事实来源，负责同步资产面板选择、画布坐标变换及属性面板配置。
- **插件化渲染引擎**：画布预览层通过 `componentRenderers` 映射表动态加载组件视图，属性配置层通过 `stylePlugins` 机制根据组件类型注入差异化表单，实现了 UI 扩展与核心逻辑的解耦。
- **数据流闭环**：Schema 管理模块定义的元数据结构直接驱动设计器的数据绑定选项，而设计器产出的模板 JSON 则通过统一的 API 服务层持久化，形成从模型定义到模板实现的完整链路。

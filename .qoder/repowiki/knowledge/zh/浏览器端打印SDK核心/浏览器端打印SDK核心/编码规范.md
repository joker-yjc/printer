- 所有渲染器（Renderer）和管道执行器（PipeExecutor）均实现统一接口，通过类型标识（type）进行注册与查找，支持插件化扩展。
- 组件渲染方法统一接收 `ComponentNode` 与 `RenderContext`，通过上下文提供的 `resolveBinding` 和 `applyPipes` 处理数据绑定与格式化。
- 布局坐标系统一使用毫米（mm）作为设计单位，渲染时通过常量 `MM_TO_PX`（96 DPI 下 1mm ≈ 3.78px）转换为像素（px）。
- 涉及数值聚合（如表格合计）时强制使用 `Decimal.js` 库进行运算，避免 JavaScript 浮点数精度丢失问题。

- 采用容器组件与展示组件分离模式，主页面文件负责 API 调用与状态管理，复杂表单与预览逻辑封装于 components 目录下的独立 Modal 组件中。
- 统一使用 Ant Design 的 Form.useForm 实例配合 Modal 组件进行受控表单管理，通过 form.setFieldsValue 实现编辑场景的数据回填。
- 在涉及 JSON 结构编辑的场景中，普遍集成 @monaco-editor/react 组件并提供语法高亮与格式化支持，替代原生 Textarea。
- 所有管理页面均实现标准化的批量操作流程，包括基于 FileReader 的 JSON 文件导入解析与基于 Blob/URL.createObjectURL 的前端导出下载。

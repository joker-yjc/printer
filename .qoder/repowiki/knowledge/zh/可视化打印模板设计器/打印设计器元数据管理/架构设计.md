- **模块化页面结构**：采用 `index.tsx` (容器/逻辑层) + `components/` (展示/交互层) 的分层模式，实现列表管理与表单弹窗的逻辑解耦。
- **统一交互范式**：三个子模块（Schema/Mock/Template）均遵循“列表筛选 + 批量操作”与“Modal 弹窗编辑”的 UI 架构，通过 Ant Design 组件库构建一致的管理体验。
- **智能辅助集成**：在 Schema 和 Mock 数据管理中集成 Monaco Editor 进行 JSON 结构化编辑，并内置基于类型推断的智能生成算法（Mock 生成与 Schema 逆向推导），形成“手动编辑-智能生成”的双模态输入边界。
- **跨模块依赖**：Template 与 Mock 模块强依赖 Schema 模块提供的元数据结构，通过共享的 `schemaApi` 与类型定义维持数据一致性。

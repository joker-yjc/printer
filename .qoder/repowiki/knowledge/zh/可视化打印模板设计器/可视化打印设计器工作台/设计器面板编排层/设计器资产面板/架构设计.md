- 入口文件 `index.tsx` 使用 Ant Design `Tabs` 组织“数据资产”与“组件库”两个子模块。
- `DataAsset/index.tsx` 负责 Schema 数据的获取与树形展示，通过 `schemaApi` 加载并转换为 `Tree` 节点，处理字段类型校验与拖拽/双击事件。
- `ComponentLibrary/index.tsx` 定义静态组件配置，提供基础、装饰及编码类组件的图标与默认属性，支持拖拽与双击交互。
- 两个子模块均依赖 `useDesignerStore` 进行全局状态管理（如 `addComponent`、`selectComponent`），并通过 CSS Modules (`index.module.css`) 实现样式隔离。

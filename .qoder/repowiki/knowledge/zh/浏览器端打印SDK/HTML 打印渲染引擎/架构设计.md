- **插件化渲染层**：定义 `ComponentRenderer` 接口（`types.ts`），通过 `renderers/index.ts` 统一导出文本、表格、条码等具体实现类。
- **工具与常量层**：`utils/styleBuilder.ts` 负责样式对象到 CSS 字符串的转换及 mm 到 px 的单位映射；`constants.ts` 集中管理默认尺寸与样式配置。
- **模板生成层**：`htmlTemplate.ts` 提供页面级 HTML 结构组装及打印/预览专用的 CSS 样式注入逻辑。
- **依赖方向**：渲染器依赖工具层处理样式，依赖上下文 `RenderContext` 解析数据，最终由模板层包装为完整文档。

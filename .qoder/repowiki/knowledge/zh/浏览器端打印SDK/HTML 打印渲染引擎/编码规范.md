- 所有渲染器类均实现 `ComponentRenderer` 接口，强制包含 `type` 标识符、`render` 方法及可选的 `calculateHeight` 方法。
- 统一使用 `styleBuilder` 中的 `buildPositionStyle` 处理绝对定位坐标转换，并通过 `buildStyleString` 将驼峰命名样式对象序列化为 CSS 字符串。
- 渲染逻辑中优先从 `RenderContext` 获取数据绑定值或分页专用数据（如 `_pageData`），并回退至组件默认配置。
- 在生成 HTML 字符串时，对表格单元格等可能包含用户输入的内容执行 `escapeHtml` 转义以防止 XSS 注入。

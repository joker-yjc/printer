- 入口层：`index.ts` 统一导出 SDK 主类、引擎、渲染器、管道工具及类型定义。
- 门面层：`PrintSDK.ts` 作为高层 API，封装预览/静默打印逻辑，通过隐藏 iframe 或新窗口执行 `window.print()`，并处理资源加载等待与生命周期清理。
- 核心引擎：`printEngine.ts` 负责数据绑定解析、管道转换执行、虚拟分页计算（含表格跨页拆分）以及 HTML 片段组装。
- 插件体系：采用策略模式，`renderers` 目录下各组件渲染器实现 `ComponentRenderer` 接口；`pipes` 目录通过注册表管理数据格式化逻辑。
- 模板生成：`htmlTemplate.ts` 集中管理打印所需的 CSS 样式与 HTML 文档结构，支持连续纸与分页纸张模式。

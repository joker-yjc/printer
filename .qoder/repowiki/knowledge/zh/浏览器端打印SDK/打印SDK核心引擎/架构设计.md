- **入口与导出**：`sdk/src/index.ts` 统一暴露 `PrintSDK`、`PrintEngine`、渲染器及管道系统，遵循完全解耦、无状态的设计原则。
- **核心分层**：
  - **API层** (`PrintSDK.ts`)：封装单次、批量及多模板打印流程，通过隐藏 `iframe` 或新窗口实现静默/预览打印，并处理资源加载等待与生命周期清理。
  - **引擎层** (`printEngine.ts`)：负责数据绑定解析、管道转换调度及复杂的虚拟分页计算（支持流式布局、表格跨页拆分、页头页脚动态适配）。
  - **渲染层** (`printEngine/renderers/`)：采用插件化设计，各组件（文本、表格、二维码等）实现 `ComponentRenderer` 接口，将逻辑节点转换为 HTML 片段。
  - **管道层** (`pipes/`)：提供注册中心模式，支持日期、货币、中文数字等数据格式化，通过 `executePipe` 动态调用。
- **依赖方向**：API 层依赖引擎层，引擎层依赖渲染层与管道层，底层依赖 `utils/resourceLoader` 进行 DOM 资源监控。

- **统一门面封装**：`PrintSDK` 作为核心入口，将 `printEngine` 的 HTML 生成能力与 `pipes` 的数据格式化逻辑解耦，对外暴露纯函数式 API。
- **批量任务编排**：在 SDK 层实现多模板/多数据的循环渲染与 HTML 片段提取（`extractBodyContent`），最终合并为单一打印文档以减少用户交互次数。
- **异步资源同步**：通过 `resourceLoader` 统一管理 iframe/新窗口中的图片及二维码加载状态，确保在触发 `window.print()` 前所有视觉元素已就绪。
- **环境隔离执行**：利用隐藏 iframe 或 `_blank` 窗口承载打印内容，通过 `afterprint` 事件或超时机制自动清理 DOM，避免污染宿主页面。

- 入口层：`sdk/src/index.ts` 统一导出 `PrintSDK`、`PrintEngine`、渲染器、管道系统及工具函数。
- 门面层：`PrintSDK.ts` 封装打印流程（预览/直接打印、批量/多模板），通过隐藏 iframe 或新窗口生成并触发打印，集成资源等待与清理逻辑。
- 引擎层：`printEngine.ts` 负责数据绑定解析、管道转换、虚拟分页计算（含表格跨页拆分）及 HTML 组装；采用插件化设计，通过 `ComponentRenderer` 接口管理各类组件渲染器。
- 扩展层：`pipes/` 提供可注册的管道执行器（如日期、货币、中文数字），`printEngine/renderers/` 实现具体组件（文本、表格、条码等）的 HTML 渲染逻辑。
- 基础支撑：`types.ts` 定义模板、组件、数据绑定等核心数据结构；`utils/resourceLoader.ts` 处理图片等资源加载等待。

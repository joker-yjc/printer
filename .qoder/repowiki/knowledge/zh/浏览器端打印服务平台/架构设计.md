- **构建与工作流编排**：根目录 `package.json` 定义了统一的启动与构建脚本（如 `build:sdk`, `build:designer`），作为整个平台的入口点，协调子模块的开发与发布流程。
- **逻辑分层与解耦**：采用“设计态”与“运行态”分离架构。Designer 负责模板的可视化生产与 Schema 管理，SDK 负责纯逻辑的数据转换与 DOM 渲染，两者通过共享的 TypeScript 类型定义与模板 JSON 结构进行隐式契约交互。
- **依赖隔离**：SDK 保持无 UI 依赖的纯净性，仅关注打印引擎核心；Designer 则聚合了 React、Ant Design 等前端技术栈，两者在物理目录与依赖树上完全隔离，确保了 SDK 可被独立集成至其他宿主环境。

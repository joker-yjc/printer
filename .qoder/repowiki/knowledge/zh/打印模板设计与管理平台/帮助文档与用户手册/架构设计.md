- **入口组件**：`index.tsx` 作为页面根节点，利用 `react-router-dom` 的 Hash 路由（`/help#id`）管理当前阅读章节状态。
- **数据配置层**：`chapters.ts` 定义文档元数据，通过 `new URL(..., import.meta.url)` 机制将 Markdown 文件路径转换为可被 Vite 等构建工具处理的资源链接。
- **渲染引擎**：`MarkdownRenderer.tsx` 集成 `react-markdown` 与 `remark-gfm`，通过自定义 `components` 映射实现统一的排版样式（如代码块、表格、引用等）。
- **导航组件**：`Sidebar.tsx` 基于 Ant Design `Menu` 组件实现左侧章节列表，支持点击切换并触发主内容区的异步加载。

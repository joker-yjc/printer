## 简介
属性面板是设计器中用于配置当前选中组件的可视化界面，覆盖以下能力：
- 布局配置：位置（X/Y）、尺寸（宽/高）等页面坐标系属性
- 样式配置：字体、颜色、对齐、边框等视觉属性；通过插件化系统支持不同组件类型
- 数据绑定：绑定路径、默认值、数据管道链式处理
- 表格列配置：列标题、字段、对齐、显示/隐藏、移动、删除、合计配置等
- 合计额外行：复杂合计场景下的额外行配置
- 实时预览与状态管理：通过全局状态驱动画布即时更新
- 扩展机制：样式插件与数据管道配置器均支持注册扩展

## 项目结构
属性面板位于设计器页面的右侧，由主入口组件负责组织各子区域，并通过全局状态管理器进行数据更新。采用CSS Grid布局系统，提供响应式的属性配置界面。

## 架构总览
属性面板采用"主容器 + 子区域 + 插件系统"的分层架构，结合CSS Grid布局系统：
- 主容器负责状态读取与变更分发
- 子区域各自封装 UI 与业务逻辑
- 插件系统以注册表形式扩展样式与管道配置器
- CSS Grid布局系统提供响应式网格布局

## CSS Grid布局系统
属性面板采用CSS Grid布局系统，提供响应式和一致性的UI体验：

### 布局特性
- **网格系统**：使用 `display: grid` 和 `grid-template-columns: 1fr 1fr` 创建两列布局
- **间距控制**：通过 `gap: 12px 16px` 控制行间距和列间距
- **响应式设计**：支持不同屏幕尺寸下的自适应布局
- **全宽支持**：`.property-item-full` 类提供全宽布局选项

### 样式类说明
- `.property-list`：主网格容器，定义两列布局
- `.property-item`：标准网格项，占1列
- `.property-item-full`：全宽网格项，占2列
- 嵌套网格：子列表继承父级网格布局，但移除外层padding

### 布局优势
- **一致性**：统一的网格间距和对齐方式
- **响应性**：自动适配不同屏幕尺寸
- **可维护性**：集中化的样式管理
- **扩展性**：易于添加新的网格项类型

## 性能考虑
- 状态更新粒度：每次变更仅更新对应字段，避免全量重渲染
- 插件与配置器按需加载：通过注册表查找，减少不必要的初始化
- 列配置区域：仅在表格组件激活，避免非必要 DOM 渲染
- 数值输入：使用受控组件与默认值回退，降低无效计算
- **CSS Grid优化**：使用高效的网格布局系统，减少DOM层级
- **列宽计算**：通过 `computeColumnMaxWidth` 函数优化列宽计算性能

## 故障排查指南
- 无组件选中
  - 现象：属性面板显示"未选中组件"
  - 处理：在画布中选择一个组件
- 样式不生效
  - 现象：修改样式后画布无变化
  - 处理：确认组件类型与插件匹配；检查 onStyleChange 回调是否正确传递；核对全局状态更新
- 数据绑定无效
  - 现象：绑定路径或默认值未生效
  - 处理：检查绑定路径是否为合法 JSON Path；确认管道配置器选项正确；核对全局状态更新
- 表格列配置异常
  - 现象：列标题/字段无法编辑或合计不显示
  - 处理：确保组件类型为 table 且存在列配置；检查隐藏状态与禁用态；确认合计开关与模式设置
- **列宽溢出问题**
  - 现象：列宽输入框显示错误状态或无法设置
  - 处理：检查表格可用宽度计算；确认列宽总和不超过表格宽度；查看溢出提示信息
- **CSS Grid布局问题**
  - 现象：属性面板布局错乱或元素重叠
  - 处理：检查CSS Grid类名使用；确认嵌套网格的padding处理；验证网格间距设置

# 需求文档：表格列级样式控制

> **版本**: v1.0
> **创建日期**: 2026-06-04
> **状态**: 设计中
> **优先级**: 中

---

## 背景

客户在使用表格组件时，需要针对**某一列**单独控制字体大小、对齐方式、字重、颜色等样式，而非所有列使用统一样式。当前表格仅支持表格级的统一样式配置，无法满足逐列差异化样式的需求。

## 需求描述

### 功能需求

**F1 - 数据单元格列级样式**

支持为每一列的数据单元格单独设置以下样式属性：

| 属性 | 说明 | 示例 |
|------|------|------|
| `fontSize` | 字体大小（px） | 12、14、16 |
| `fontWeight` | 字重 | `'normal'`、`'bold'`、`600` |
| `color` | 文字颜色 | `'#333'`、`'red'`、`'rgb(255,0,0)'` |
| `backgroundColor` | 背景颜色 | `'#f0f0f0'`、`'transparent'` |
| `textAlign` | 对齐方式 | `'left'`、`'center'`、`'right'` |

**F2 - 表头单元格列级样式**

支持为每一列的表头单元格单独设置样式属性，属性集与 F1 相同。

**F3 - 表格级表头默认样式**

支持在表格属性中设置表头全局默认样式（当前表头背景色 `#fafafa`、字重 `600` 是硬编码的），列级 `headerStyle` 可覆盖此全局默认值。

### 约束条件

- **向后兼容**：所有新字段均为可选，未配置时行为与现有版本完全一致
- **不涉及合计行**：合计行已有独立样式配置（`TableSummaryStyle`），列级样式不应用到合计行
- **不涉及合计额外行**：继续使用 `SummaryExtraRow` 自身的样式配置

### 非功能性需求

- 设计器配置面板操作流畅，不过度增加面板高度
- SDK 渲染结果与设计器画布预览一致

## 用户场景

### 场景 1：高亮金额列

客户有一张销售明细表，「金额」列希望用红色加粗显示，其他列保持默认样式。

```
配置：
  金额列: style.fontWeight = 'bold', style.color = 'red'
结果：
  金额列数据以红色加粗显示，表头、其他列不变
```

### 场景 2：表头居中对齐

客户希望表头文字居中显示，但数据列保持左对齐（数字除外）。

```
配置：
  表格级: headerStyle.textAlign = 'center'
  金额列: headerStyle.textAlign = 'center', style.textAlign = 'right'
结果：
  所有表头居中，金额列数据右对齐，其他列数据左对齐
```

### 场景 3：表头背景色区分

客户希望不同列的表头用不同颜色区分。

```
配置：
  名称列: headerStyle.backgroundColor = '#e6f7ff'  (浅蓝)
  金额列: headerStyle.backgroundColor = '#fff7e6'  (浅橙)
结果：
  各列表头呈现不同背景色
```

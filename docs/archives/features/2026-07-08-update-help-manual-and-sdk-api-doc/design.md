# 方案设计：更新用户手册并新建 SDK API 参考文档

## 总体策略

采用「设计器内闭环」的思路：

- **设计器用户手册**面向模板设计人员，聚焦界面操作和可视化配置，保持章节结构不变，仅做增量更新。
- **SDK 接入文档**直接作为设计器用户手册的最后一章，引导用户从「设计完模板」到「在代码中调用打印」的完整路径。
- **`sdk/README.md` 保持完整**：因为 `@jcyao/print-sdk` 会作为独立 npm 包发布，npm 页面默认只渲染 `README.md`，拆分会降低 npm 用户的阅读体验。

## 设计器用户手册更新点

### 05-设计器基础.md

- 在「三个区域」后补充页头/页脚高度调整说明：
  - 启用后可输入最小高度。
  - 拖拽底部/顶部边框可手动调整。
  - 内容跨区域拖拽时不再自动撑高，改为按最小高度约束。

### 06-组件使用指南.md

- 在表格组件配置中补充「表格列管理」的列级样式能力：
  - 表头样式：字号、字重、颜色、对齐
  - 数据单元格样式：字号、字重、颜色、对齐

### 08-表格高级配置.md

- 将「启用合计行」旧布尔描述更新为 `summaryDisplay` 三种模式：
  - `both`：显示合计行 + 额外行
  - `none`：隐藏合计行和额外行
  - `extra-only`：仅显示额外行
- 在「表格全局设置」中新增 `density` 密度预设说明：
  - `normal`：常规密度
  - `compact`：紧凑密度，节省纸张

### 09-页面设置.md

- 在「页码配置」中新增「自定义位置」小节：
  - 位置选项增加 `custom`
  - 说明 `customX`、`customY` 以页面左上角为原点
  - 说明设计器中可拖拽蓝色虚线框调整位置

在 `designer/src/help/docs/12-SDK接入.md` 中按以下结构编写：

- 多模板批量打印
## 自定义数据管道

内容定位：从设计器用户视角出发，强调「设计完模板后如何调用 SDK」，不过度展开底层类型细节，细节链接到 npm 包 README。

- 页码自定义位置拖拽示意

截图通过启动本地设计器（`npm run start`）后使用浏览器工具截取，保存到 `designer/src/help/docs/images/`。

## 一致性约束

- 所有示例代码字段以 `sdk/src/types.ts` 为准。
- 枚举值统一使用实际类型中的字符串（如 `PageConfig.size` 使用 `'A4' | 'A5' | 'CUSTOM' | 'CONTINUOUS'`）。
- 链接使用相对路径，确保在 GitHub 和本地帮助弹窗中均可访问。

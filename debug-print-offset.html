📌 问题根因

设计时（Canvas）：画布没有 padding，组件 xMm = 0 位于纸张最左边缘。

修复前打印：.print-page 有 padding-left: marginLeft。 由于 position: absolute 的 left 是相对于 padding box 计算的， 所以 xMm = 0 的组件实际距离纸张左边缘 = marginLeft。

修复前实际偏移量 = marginLeft （所有内容整体右移）
当 marginLeft > marginRight 时，内容中心偏左（视觉"偏左"）

🔧 修复方案

去掉 .print-page 的 padding，让组件坐标直接映射到纸张坐标系：

/* generatePrintPageStyles / generateBatchPrintStyles */
.print-page {
  width: ${pageWidthMm}mm;
  height: ${pageHeightMm}mm;
  padding: ${marginTop}mm ${marginRight}mm ${marginBottom}mm ${marginLeft}mm;
  /* padding 已删除 */
}

@media print {
  .print-page {
    margin: 0 !important; /* 覆盖所有方向的 auto margin */
    box-shadow: none;
  }
}

此方案无需改动设计器、组件渲染器、分页逻辑，仅修改打印样式模板即可。 所有现有模板的坐标数据也无需迁移。
